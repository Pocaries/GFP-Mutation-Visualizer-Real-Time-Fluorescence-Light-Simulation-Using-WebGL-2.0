# GFP-Mutation-Visualizer-Real-Time-Fluorescence-Light-Simulation-Using-WebGL-2.0
This paper presents a WebGL 2.0-based real-time visualization tool for simulating the fluorescence emission of Green Fluorescent Protein (GFP) and four engineered variants: BFP (Blue), CFP (Cyan), YFP (Yellow), and RFP (Red).
